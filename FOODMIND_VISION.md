# FoodMind App Web

## Misión

Ayudar a los hogares a reducir desperdicios, controlar caducidades y gestionar su alimentación mediante una aplicación inteligente y sencilla.

---

## Objetivo V1

Desarrollar una aplicación web instalable (PWA) que permita:

- Gestionar inventario de alimentos.
- Controlar fechas de caducidad.
- Gestionar lista de la compra.
- Consultar un dashboard del estado de la despensa.
- Funcionar desde móvil y ordenador.

---

## Funcionalidades MVP

### Dashboard

- Total de productos
- Productos próximos a caducar
- Productos caducados
- Productos en lista de compra

### Inventario

- Añadir productos
- Editar productos
- Eliminar productos
- Fecha de compra
- Fecha de caducidad
- Cantidad
- Ubicación

### Lista de compra

- Añadir productos
- Marcar como comprados
- Eliminar productos

### Ajustes

- Perfil
- Preferencias
